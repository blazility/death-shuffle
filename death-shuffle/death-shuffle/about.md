# Death Shuffle

Every time you die, the level music switches to a **random song you downloaded with Jukebox**.

- Picks from every NONG you have downloaded in Jukebox (local files, YouTube and hosted songs)
- Never picks the same song twice in a row
- Shows the new song's name when it changes
- Works in practice mode (can be turned off)
- Optionally shuffles the very first attempt too, and can include normal GD songs

Requires **Jukebox**.
